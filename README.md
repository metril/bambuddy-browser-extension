# Bambuddy browser extension

Chrome (MV3) extension that sends models from MakerWorld, Printables and Thingiverse into a Bambuddy library, with profile and folder pickers, duplicate detection and bulk MakerWorld collection import.

Status: in development

## Install (unpacked)

1. Open `chrome://extensions` and enable Developer mode.
2. Click "Load unpacked" and select this folder.
3. Open the extension options, enter your Bambuddy URL and API key, and run "Test connection".
